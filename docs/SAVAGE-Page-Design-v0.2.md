# SAVAGE 页面设计 v0.2 · 浅色方向

日期：2026-10-15。调整依据：用户反馈上一版过暗，希望更换页面设计。本文覆盖 v0.1 的配色与视觉表达，页面行为和产品规则继续采用 v0.1 / PRD v4.1。

## 视觉概念

![浅色六屏概念](../design/concepts/savage-core-screens-v2-light.png)

保留首页、邀请、准备、专注、恢复、战报六屏。首页与战报有轻松的熊贴纸；普通页面以暖白和深色文字为主，青柠绿用于主行动，浅紫用于手机插画和头像。专注页保持低亮暗色。此版本取代深紫作为普通页面主背景的旧方向。

## 新配色基准

| 用途 | 色值 | 使用说明 |
|---|---|---|
| 普通页面背景 | #FAF9F5 | 暖白纯色，首页/邀请/准备/战报 |
| 主文字 | #242328 | 标题、正文、按钮文字 |
| 次文字 | #64616A | 辅助说明；最终渲染仍需检查对比度 |
| 主行动 | #C5F36B | 青柠绿按钮，搭配深色文字 |
| 辅助色 | #E8E2FB | 头像与手机插画，不作大面积深色背景 |
| 专注背景 | #242B29 | 柔和炭灰；不显示其他人的实时状态 |
| 恢复背景 | #DDE6DB | 鼠尾草绿；配深色文字和小面积暖黄进度 |

## 交互与细节

- 标题保留粗体辨识度，正文和按钮后续使用更清晰的常规 UI 字体。
- 按钮圆角建议 18；边距 24；触控区域设计目标至少 48 × 48。
- 邀请房主状态改为 Joined，避免与扣放就绪混淆。
- 准备页本机显示 Place phone down，真正扣放稳定后才能进入 Ready。
- 保留直接可见的 Study solo，挑战开关默认关闭。
- 恢复页不闪烁，不调整系统亮度。由于专注与恢复底色不同，进入原型时需检查暗环境下的明暗变化；如刺激明显，两页一起采用柔和鼠尾草色模式，或恢复页沿用专注底色，仅改变文字和进度颜色。

已目视检查六屏完整性、主要英文文案、Solo 入口、默认关闭的挑战、准备状态和浅色主题一致性。生成图有轻微纹理、按钮颜色和字号近似，不能作为精确取色规范；实际实现以 token 为准。专注数字后续仍需降低亮度并检查可读性。
